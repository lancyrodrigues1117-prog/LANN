How the cost is found. Each quote line is matched to the price list by item name — exact first, then closest name. A line that can’t be matched shows cost 0 and is excluded from the totals, so the margin you see is never flattered by a missing cost. Margin vs markup. Margin is profit ÷ selling price; markup is profit ÷ cost. 70% markup is only a 41.2% margin — the advisor always says which one it used. Bands. Margin at or above target reads green, within 10 points below reads amber, further below reads red.
